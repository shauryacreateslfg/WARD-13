# WARD-13

## about my project
youre made to fill a patient intake form for St. Maren's General Hospital. you are filling your own admission form with some basic information about yourself.

## tech stack
raw HTML, [TailWind](https://tailwindcss.com/) CSS and CSS for styling, and JavaScript for logic.

## running locally
no install needed. just open `index.html` in a browser.
```
git clone https://github.com/shauryacreateslfg/WARD-13
cd ward13
open index.html
```
or drop the folder into [VS Code Live Server]
